# Repository guidance

Before changing VBHC extraction, prediction schema, benchmark metrics,
benchmark artifacts, evidence traces, or related tests, read:

- `docs/ocr_pipeline_benchmark_metrics.md`

Treat that document as the current source of truth for the 13-field API
contract and benchmark policy.

Preserve ground truth and unrelated working-tree changes. Do not introduce
filename-specific or GT-specific extraction rules.
